# For Sneha 🤍 — Digital Love Card & Apology Website

A single-page, mobile-first interactive romantic apology website designed to feel like a handwritten digital love card that Sneha taps through one screen at a time. Built with pure HTML, CSS, and vanilla JS.

---

## 🚀 Quick Setup for GitHub Upload

All required files are ready in this repository:
- `index.html`: Complete standalone web application.
- `style.css`: Soft pastel styling & animations.
- `script.js`: State manager, choices, and WhatsApp messaging.
- `music.mp3` *(optional)*: Add a soft background `.mp3` song if desired.

---

## 📱 How Her Answers Are Sent

When Sneha picks her choices on Screen 9 and taps **"Send to him on WhatsApp 💬"**:
1. Her selections and custom note are copied to her phone's clipboard.
2. WhatsApp opens directly addressed to **`+91 9736360809`** with the message ready to send!

## 🌐 How to Upload to GitHub & Host for Free (GitHub Pages)

### Method A: Using GitHub Website (Simplest — No Git Command Line Needed)

1. Go to **[GitHub.com](https://github.com/)** and log in (or sign up for a free account).
2. Click the **`+`** icon at the top right and select **New repository**.
3. Name your repository (e.g. `for-sneha` or `sneha-love-card`).
4. Set visibility to **Public** (required for free GitHub Pages).
5. Click **Create repository**.
6. On the new repository page, click **uploading an existing file**.
7. Drag and drop all files from this folder (`index.html`, `style.css`, `script.js`, `README.md`, `.gitignore`) onto GitHub.
8. Scroll down and click **Commit changes**.
9. **Enable Free Website Hosting (GitHub Pages)**:
   - Go to **Settings** (top menu of your repo) → **Pages** (left sidebar).
   - Under **Build and deployment** → **Branch**, select `main` (or `master`) and `/ (root)`.
   - Click **Save**.
10. In ~1 minute, GitHub will give you a live link:
    ```text
    https://<your-github-username>.github.io/<repository-name>/
    ```
11. Send this link to Sneha 🤍!

### Method B: Using Git Command Line

If you have `git` installed on your computer, run these commands in terminal inside this folder:

```bash
git init
git add .
git commit -m "Initial commit for Sneha's love card"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

Then go to **Repository Settings > Pages** and select the `main` branch to make it live!
